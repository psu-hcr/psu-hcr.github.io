Human-Centered Robotics Lab Project

Spot Micro Quadruped Robot Dog

Github

This project is essentially about bringing a Spot Micro Quadruped to life. It’s a 12-servo robot dog inspired by the famous Boston Dynamics designs, built to mimic the way a real animal moves.

The basic architecture revolves around two microcontrollers- Teensy 4.0, and Arduino Nano, and an IMU- MPU6050. So far, I've successfully demonstrated the robot's multi-directional pitch and roll auto-levelling capabilities .

A brief summary of the control algorithm used is as follows:

A 50 Hz closed-loop PD controller fuses MPU6050 gyro and accelerometer data via an adaptive, vibration-rejecting complementary filter to dynamically level the body by differentially compressing and extending all four legs with slew-rate-limited servo corrections.
